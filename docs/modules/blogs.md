# Module: Guides (blogs)

## What it does

Storefront content: charging tips and accessory advice.

- `/blogs` — published guides.
- `/blogs/[slug]` — full post.
- Homepage Field notes shows the latest three as 3D plates.

Admin creates/edits/publishes under `/admin/blogs`.

## Key files

- `app/blogs/page.jsx`
- `app/blogs/[slug]/page.jsx`
- `components/home/HomeFieldNotes.jsx`
- `app/admin/blogs/`
- `components/admin/BlogForm.jsx`
- `app/api/blogs/`
- Featured images under `public/images/blog/`

## Rules to keep

- Storefront shows `PUBLISHED` only.
- Field notes: clean 3D desk, one row of plates, not a overlapping fan.
- Keep accessory-topic copy (USB-C, watts, earbuds), not old spice content.
