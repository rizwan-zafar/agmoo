# Module: Content pages

## What it does

Static storefront pages that are not catalog.

- `/about` — Agmoo story and accessory positioning.
- `/contact` — contact form → `ContactMessage` in MySQL; admin reads them in Messages.

## Key files

- `app/about/page.jsx`
- `app/contact/page.jsx`
- `components/ContactForm.jsx`
- `app/api/contact/`
- `app/admin/messages/page.jsx`

## Rules to keep

- Brand is Agmoo mobile accessories, not spices.
- Contact submissions must show in admin Messages with unread state.
