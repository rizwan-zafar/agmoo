# Module: Shared UI

## What it does

Reusable storefront + admin pieces: buttons, inputs, table, modal, pagination, empty/error/spinner, toasts, smart images, brand mark.

Admin list tables use `Table` with `.admin-table` styles. Toasts sit bottom-right (shop flying accessories avoid that corner for clicks, but they roam the page).

## Key files

- `components/common/*`
- `components/common/ToastContext.jsx`
- `components/common/BrandMark.jsx`
- `components/common/SmartImage.jsx`

## Rules to keep

- Plain JS React. No TypeScript unless requested.
- Palette: ink + electric cyan (`app/globals.css` tokens).
- Fonts: Outfit (headings) + Inter (body).
